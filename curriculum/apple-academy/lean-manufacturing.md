## Part 1 — INTRO TO LEAN

- **2.2 What is Lean / sources of waste:** the classic wastes — **inefficient
  processes, wasted materials, lack of standardization, over/under-production
  (Just-In-Time issues), and wasted movement/motion.** Lean = systematically
  remove waste.
- **Lean principles = a continuous cycle** (think DMAIC): **Define & measure →
  analyze & improve → implement & validate → control & sustain.**
- **2.3 Define current condition → Process Capability:** define **requirements +
  spec limits (LSL / USL)**, visualize them, **monitor actual performance**, assess
  **stability & distribution**, then compute **process capability** (are you
  reliably inside spec?).
- **2.4 OEE / TEEP:** **OEE = Availability × Performance × Quality.** TEEP factors
  in utilization (all available time). Watch the **Six Big Losses** grouped under
  **Availability loss, Performance loss, Quality loss.**
- **2.5 Quantifying value-add (5 steps):** define **value-added**, set a **lean
  activity classification**, **classify each process step**, run a **motion study**,
  then **quantify the VA%** (what fraction of work actually adds value).

**Toby's one-liner:** *Find the waste → measure capability and OEE → quantify
value-add → improve and sustain.*

## Part 2 — LEAN ANALYSIS EXAMPLE (a worked case)

A 5-move improvement story: **Define the problem** (initial condition + objective)
→ **Develop & apply lean solutions** (execution method) → **Quantify & summarize
the gains** → **Deep dive: setup-time reduction** → **Lessons learned.**

**Toby's one-liner:** *Lean isn't a vibe — it's problem → solution → measured gain
→ lesson, every time.*
