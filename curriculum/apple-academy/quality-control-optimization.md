## Part 1 — INTRODUCTION TO SMART FACTORY

- **2.2 What is a smart factory:** connected machines + systems that **share
  real-time data and automate decisions** to continuously improve quality and
  productivity.
- **2.3 Key standards (know what each covers):**
  - **ISO 23247** — Digital Twin framework (digital copies of real machines/processes).
  - **RAMI 4.0** — reference model for connecting machines/systems/data (Industry 4.0).
  - **NIST CPS Framework** — rules for cyber-physical (smart, connected) systems.
  - **IEC 62264 / ISA-95** — integrate enterprise (office) with control (shop floor).
  - **IEC 62443** — industrial cybersecurity (ties back to your Cybersecurity course).
- **2.4 Why we need it:** manual, reactive quality can't keep up; connected data
  enables prevention.

## Part 2 — PREVENTION & OPTIMIZATION USING DATA

**The core framework — the 4-step data strategy (memorize):**
**Collect → Visualize → Alert → Execute.**

- **3.3 Collect** — gather usable data (sensors, equipment logs, test results,
  **images**, ops data). Four habits: **Categorization, Standardization, Ownership,
  Optimization.** Data is a team effort.
- **3.4 Visualize** — turn it into **dashboards / auto reports** so people see issues fast.
- **3.5 Alert** — notify when data signals trouble: **conventional monitoring** +
  **anomaly detection from machine/test images** *(← this is computer vision / ML —
  your throughline made literal).*
- **3.6 Execute** — act: move from **traditional sampling → smart adaptive
  sampling**; transform **OQC (Outgoing Quality Control)** with real-time data;
  connect data sources; **automate responses**; engineer solutions from automated
  analysis.

**Toby's one-liner:** *Smart factory = connected real-time data; and the playbook
is Collect → Visualize → Alert (incl. image anomaly detection) → Execute.*
