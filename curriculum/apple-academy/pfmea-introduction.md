## Part 1 — PFMEA OVERVIEW

- **PFMEA = Process Failure Modes and Effects Analysis** — a **prevention** tool to
  find where a process could fail *before* it does, so you fix risk early instead of
  "build → test → fix → repeat."
- **Family:** **DFMEA** (design) feeds **PFMEA** (process). Start with design, then
  analyze the process that builds it.
- **The 5 core steps:** **define process + team → identify failure modes → assess
  risk → corrective action → review & update.**

## Part 2 — PFMEA SCOPING

- **3.2 When:** start **early** (concept/planning) and **update** at every stage and
  whenever the process changes or new risks appear.
- **3.3 Node selection** — don't analyze everything; focus where risk is highest.
  Cast a wide net → map the supply chain → focus with **N.U.D.D.** (**New, Unique,
  Difficult/Different**) → select the node → outline the critical process.
- **3.4 Define the team** — cross-functional: process/quality/design engineers,
  operators, etc. PFMEA is a team sport.

## Part 3 — CONDUCT PFMEA & TAKE ACTION

- **4.2–4.3 Map it:** **flow chart** the process; build a **block diagram** with
  **inputs/outputs** and **CTQ (Critical-to-Quality)** characteristics.
- **4.4 The PFMEA template (the heart of it).** Columns: **Process step → CTQ /
  Function → Potential failure mode → Effect → Cause → Prevention control →
  Detection control →** ratings **Severity (S), Occurrence (O), Detection (D) →
  RPN.**
  - **RPN = Risk Priority Number = S × O × D.** Higher RPN = fix first.
- **4.5 Recommended actions:** complete actions → re-score S/O/D → **recalculate
  RPN** → file/share → repeat on every change.
- **4.6 GenAI/LLM tools — support + caution:** they can speed access to industry
  knowledge and boost productivity, **but**: don't paste **sensitive/proprietary
  info** into them, don't let them violate core PFMEA principles, and keep a human
  expert in the loop. *(This mirrors AI Fluency's Discernment & Diligence.)*
- **5.1 Ongoing tool:** PFMEA is a living document, not a one-time task.

**Toby's one-liner:** *Scope with N.U.D.D. → fill the template (failure → effect →
cause → controls) → prioritize by RPN = S×O×D → act, re-score, repeat — and use AI
carefully.*
