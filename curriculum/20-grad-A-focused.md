# 20 — Graduate Plan A: "Focused" (Robotics + Machine Learning)

> The graduate program is a **separate, ongoing learning period**. Start it after
> the undergrad track (or once you've cleared the technical-literacy threshold:
> comfortable with the ML Specialization material and basic Python reading).

**Theme:** The credentialed spine — deep learning → reinforcement learning →
robotics → a simulated robot you actually train.
**Best if:** you want graduate-level robotics+ML capability and certificates
without the full research-grade detour.

| | |
|---|---|
| **Estimated workload** | ~520 hrs |
| **Duration (3 hr/day)** | **~6.6 months** |
| **Range** | ~10 mo (2 hr/day) → ~5 mo (4 hr/day) |
| **Cost** | ~$0–$400 (DL Spec + Modern Robotics certs via financial aid → near $0; HF + Isaac + ROS free) |
| **Certificates earned** | DeepLearning.AI Deep Learning Specialization · Hugging Face Deep RL · Modern Robotics (Northwestern) + capstone · (optional) NVIDIA DLI |
| **Prereq** | Intro ML literacy + basic Python reading (covered by undergrad). Refresh linear algebra + probability first. |

---

## Phase 1 — Core Deep Learning (~10 weeks, ~150 hrs)

| Course | Hrs | Cert | Why |
|---|---|---|---|
| **DeepLearning.AI — Deep Learning Specialization** | ~120 | ✅ (~10 ACE credit rec) | The credentialed backbone: neural nets, CNNs, sequence models/attention. |
| **MIT 6.S191** Intro to Deep Learning | ~15 | — | Fast conceptual survey run in parallel — keeps the big picture in view. |
| Linear algebra + probability refresh (Khan/3Blue1Brown) | ~15 | — | The load-bearing math for everything after. |

**Milestone:** train and explain a small image classifier; describe what each
layer is doing.

## Phase 2 — Reinforcement Learning, the bridge (~7 weeks, ~80 hrs)

| Course | Hrs | Cert | Why |
|---|---|---|---|
| **Hugging Face — Deep RL Course** | ~50 | ✅ free | Hands-on RL with a free certificate; trains agents in Colab. RL is the connective tissue to robotics. |
| Concept reading (PPO / Q-learning intuition) | ~30 | — | Understand *why* the agent improves, not just the API. |

**Milestone:** train an RL agent to solve a control task; write up the reward design.

## Phase 3 — Robotics Fundamentals (~12 weeks, ~180 hrs)

| Course | Hrs | Cert | Why |
|---|---|---|---|
| **Modern Robotics Specialization** (Northwestern, K. Lynch) | ~150 | ✅ + capstone | The brand-name rigorous sequence: configuration space, kinematics, dynamics, planning, control, manipulation. |
| **Official ROS 2 Tutorials** (alongside) | ~30 | — | The standard robotics tooling; do these throughout. |

**Milestone:** complete the **Modern Robotics capstone** — a mobile-manipulator
controller in simulation.

## Phase 4 — Applied Capstone (~5 weeks, ~110 hrs)

| Course | Hrs | Cert | Why |
|---|---|---|---|
| **NVIDIA Isaac Sim / Isaac Lab** — "Train Your First Robot" | ~40 | DLI cert (if assessed) | Combine Phase 2 (RL) + Phase 3 (robotics) in a GPU sim. |
| NVIDIA DLI — one 8-hr assessed course | ~16 | ✅ | Bank an extra named certificate. |
| **Capstone project** | ~54 | — | See below. |

**Capstone deliverable:** in Isaac Lab, train an RL policy on a robot model to
complete a task; document the approach, results, and what you'd do for sim-to-real.

---

## What you finish with
Graduate-level fluency across deep learning, reinforcement learning, and robotics
— three brand-name certificates and a simulated robot you trained end-to-end — in
roughly two academic terms.

## Next step
Extend into **Grad Plan B** for vision + real mobile-robotics depth, or stop here
with a strong, demonstrable robotics+ML portfolio.
